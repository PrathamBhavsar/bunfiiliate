# Surface brief: landing site

Scope: marketing landing (Persuade) + docs (Read), `site/`. Code-led. Direction pinned by the user (brief beats the roll): dark, GeistPixel-Square display, Satoshi body, ASCII canvas hero, Hugeicons, refs impeccable.style / astryx / prometheus.io / hermes-agent / sherlockproject.

Audience/job: developer decides to self-host in one viewport, copies install line. Proof: live GitHub numbers, benchmark doc, ledger invariant. No invented claims.

## Direction contract
THESIS: The page proves one invariant: money in a ledger always sums to zero. Refuses the SaaS hero + icon-card grid.
OWN-WORLD: Ink-black ground tinted green (#07090a), bone text, acid-green #b8ff3c as one saturated field (install band) plus sparse marks. Square corners, 1px hairlines, pixel display type, Satoshi body, Geist Mono for code only. Ledger rows, digits, receipts.
STORY: A visitor sees clicks fall into a ledger that stays balanced, believes the engine is exact, copies the install line, and reads docs.
FIRST VIEWPORT: Full-bleed ASCII rain; left column: pixel headline (2 lines, ~96px), one-sentence sub, install line with copy button, Get started + GitHub. Bottom-right of canvas: live ledger rows (DR/CR) with a running sum pinned at 0. Nav top.
FORM: ASCII click-rain + ledger floor, position 1 of own list; seed: none (unavailable).
FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
